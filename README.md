# RogueByte POS — نظام نقاط البيع وإدارة المخزون المتكامل

نظام نقاط بيع سحابي متطور، فائق السرعة، ومصمم خصيصاً لتلبية متطلبات التجارة والتجزئة في سلطنة عُمان والوطن العربي مع دعم كامل لمعايير الفوترة الضريبية الإلكترونية وإدارة الفروع والصلاحيات المتعددة.

---

## 🌟 مميزات النظام (Key Features)

- 💳 **دعم كامل لجميع طرق الدفع (Payments)**:
  - دفع نقدي (Cash) مع فئات نقدية سريعة وحساب المتبقي (الصرف).
  - بطاقات مصرفية (Visa, MasterCard, بطاقات الخصم المباشر عبر أجهزة POS).
  - دفع مجزأ (Split Payment) يجمع بين النقد والبطاقة مع احتساب تلقائي للمتبقي.
  - بيع آجل / على الحساب (Credit / On-Account) مع تسجيل العميل وهاتفه وتاريخ الاستحقاق.
- 📦 **إدارة المخزون بدقة متناهية (Accurate Inventory Management)**:
  - متابعة دقيقة لحركة المخزون، والكميات، والتنبيه التلقائي للمخزون المنخفض.
  - حساب هوامش الربح التقديرية (Profit Margins) بناءً على سعر التكلفة وسعر البيع.
  - سندات تعديل المخزون اليدوي (توريد جديد، تالف ومنتهي الصلاحية، تسوية الجرد الفعلي).
- 📸 **إضافة المنتجات مع رفع الصور والباركود (Product Images & Barcode)**:
  - إمكانية رفع صور المنتجات مباشرة من الجهاز مع المعاينة الفورية.
  - توليد وطباعة ملصقات الباركود والأسعار للطابعات الحرارية.
  - قارئ باركود تفاعلي يدعم الكاميرا وقارئات الباركود الليزرية اللاسلكية USB.
- 🏢 **إدارة الأفرع المتعددة (Multi-Branch Support)**:
  - دعم شبكة الفروع (مسقط، صلالة، صحار، وغيرها).
  - تخصيص أرقام السجلات التجارية، الهواتف، والعناوين لكل فرع.
  - سهولة التبديل بين الفروع النشطة.
- 👥 **الموظفون وصلاحيات الأدوار (Staff & Role-Based Access)**:
  - **كاشير (Cashier)**: تشغيل نقطة البيع، مسح الأصناف، استلام المبالغ، وتعليق الطلبات.
  - **محاسب (Accountant)**: مراجعة سجل الفواتير، الأرباح والخسائر، ضريبة 5% المحصلة، وإدارة المصروفات التشغيلية.
  - **المدير / النظام (Manager / Admin)**: تحكم وإشراف شامل بكل إعدادات النظام، التسعير، الأفرع، والموظفين.
  - تبديل سريع للمستخدمين عبر لوحة أرقام PIN السرية (4 أرقام).
- 🧾 **تخصيص الفواتير الضريبية وشعار المنشأة (Receipt & Logo Customization)**:
  - فاتورة ضريبية مبسطة متوافقة مع اشتراطات حماية المستهلك والضريبة.
  - إمكانية رفع شعار المنشأة ليظهر أعلى الفاتورة الحرارية.
  - دعم مقاسات الورق الحراري (80 ملم، 58 ملم، A4) مع أمر طباعة مباشر.
  - رمز الاستجابة السريع QR Code للتحقق من الفاتورة.
- 🇴🇲 **العملة الرسمية والضريبة**:
  - العملة الافتراضية: الريال العماني (OMR / ر.ع.) بدقة 3 خانات عشرية (1.000).
  - ضريبة القيمة المضافة: 5% المطبقة في سلطنة عُمان مع إمكانية التعديل.
- 🌐 **دعم كامل للغتين (العربية والإنجليزية)**:
  - واجهة عربية كاملة RTL بتصميم عصري وأنيق.
  - واجهة إنجليزية كاملة LTR مع زر تبديل فوري بنقرة واحدة.
- 💾 **النسخ الاحتياطي (Backup & Restore)**:
  - تصدير كامل لقاعدة البيانات والمبيعات كملف JSON واستعادتها في أي وقت.
